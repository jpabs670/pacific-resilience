# Security Policy

## Supported versions

Pacific Resilience is pre-release software. Only the latest commit on the default branch is maintained.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, personal data, or information about a real site. Use GitHub's private vulnerability-reporting feature when it is enabled for this repository.

## Safety boundary

This project is designed for monitoring, simulation, and human decision support. It must not directly control breakers, generators, transfer switches, batteries, or other safety-critical equipment.
