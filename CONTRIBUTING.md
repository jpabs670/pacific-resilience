# Contributing

Pacific Resilience is currently an early reference implementation. Focused issues and small pull requests are welcome.

## Before opening a pull request

1. Keep the system read-only toward physical equipment.
2. Use synthetic or explicitly public test data only.
3. Add or update tests for behavior changes.
4. Run `npm run check`, `npm test`, and `npm run typecheck`.
5. Explain any change to trust boundaries, retry behavior, data provenance, or identifier semantics.

Please open an issue before proposing a large architectural change.
